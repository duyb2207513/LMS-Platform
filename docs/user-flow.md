User flow là đường đi của người dùng qua các màn hình.

## Student flow

```
Trang chủ
→ Đăng ký
→ Đăng nhập
→ Danh sách khóa học
→ Tìm kiếm/lọc
→ Xem chi tiết khóa học
```

## Instructor flow

```
Đăng nhập
→ Instructor Dashboard
→ Danh sách khóa học của tôi
→ Tạo khóa học
→ Chỉnh sửa
→ Upload thumbnail
→ Publish
```

## Admin flow

```
Đăng nhập
→ Admin Dashboard
→ Quản lý category
→ Tạo/sửa/xóa category
```
